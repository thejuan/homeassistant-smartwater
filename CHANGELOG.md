# Changelog

## v1.0.0 — 2026-06-29

Initial release.

- Water level, days remaining, average daily use, battery, signal, and sensor status sensors
- Alert binary sensors: any alerts, battery low, clean tank, water low, days remaining low, filter, connectivity, reporting, abnormal usage
- Firebase Auth with automatic token refresh
- Reauth flow for credential rotation
- Polls every 5 minutes (300 seconds)
